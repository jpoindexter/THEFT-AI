# MCP

MCP in Cofounder is powered by **Composio**.

You can find it from **Integrations**, under the **MCP** tab.

From there, you can connect additional apps for your workspace and make them available to agents.

## How It Works

1. Open **Integrations**.
2. Go to the **MCP** tab.
3. Search for the app you want to connect.
4. Complete the connection flow.
5. Use it from the relevant agent once it is available.
